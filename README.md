A personal LeetCode tracking tool designed to focus on pattern-based learning, not memorization.

## Motivation
While practicing LeetCode, I realized that simply solving problems was not helping me improve.

The real goal is to:
* recognize patterns quickly
* understand solutions deeply
* avoid memorizing code




## Learning Approach

This tracker is built around a structured method:
- Pattern Recognition - Identify reusable problem-solving strategies
- Active Learning - Rewrite and explain solutions in my own words
- Mistake Tracking - Document what I misunderstood
- Spaced Review - Revisit problems to reinforce understanding

## Features
- Add and track LeetCode problems
- Categorize by pattern (e.g., Dynamic Programming, DFS, BFS, etc)
- Write key ideas in plain English
- Record mistakes and gaps in understanding
- Store time & space complexity

## Tech Stack
- HTML
- CSS
- JavaScript
- Firebase for Authentication

## How to Use
1. Add a problem after solving or reviewing it
2. Focus on writing the pattern and key idea, not just code
3. Track mistakes to avoid repeating them
4. Revisit problems based on your review schedule
